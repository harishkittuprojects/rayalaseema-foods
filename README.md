# Rayalaseema Cloud Kitchen (Rayalaseema Foods) 🥗

A modern, fast-loading, premium, and responsive food e-commerce & meal subscription platform.

## 🚀 Live Demo & Hosting
Easily deployed on [Vercel](https://vercel.com).

## 🌟 Key Features
- **Online Food Bowl Ordering**: Veg Bowls, Non-Veg Bowls, and Fruit Bowls with authentic Rayalaseema spices.
- **Subscription Plans**: 10-Day Trial and Monthly regular workday lunch plans with absence pause/resume.
- **Interactive Delivery Calendar**: Interactive calendar tracking delivered, upcoming, and paused meal days.
- **Corporate & Event Catering**: Custom enquiry & instant quotation system for office lunches, team events, and bulk wholesale supply.
- **Full E-Commerce Cart & Checkout**: Live quantity adjustments, dynamic cart count, promo coupons (`RAYALA10`), GST calculation, and order tracking confirmation.
- **Customer Dashboard**: Real-time progress bar, upcoming meal alerts, and delivery history.
- **Modern Tech Stack**: HTML5, Tailwind CSS, AOS (Animate on Scroll), Vanilla JavaScript (Modular ES6 Architecture).

## 🛠️ Local Development
Open `index.html` directly in any web browser, or run a local server:

```bash
# Using Python
python -m http.server 8080

# Or using npx serve
npx serve .
```

## 📦 Deployment to Vercel
1. Import this repository in [Vercel Dashboard](https://vercel.com/new).
2. Framework Preset: **Other** (Static Site).
3. Root Directory: `./`
4. Click **Deploy**.
